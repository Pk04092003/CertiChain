# V107 Template Editor Enhancements

- Added a Page colour section to the Template Editor with a native colour picker, preset colour swatches, and a reset-to-white control.
- The chosen colour updates the certificate sheet directly and is saved through the existing template `background` field.
- Added a Single line element button to insert a horizontal line on the certificate page. The line uses the existing element selection, move/rotate, and export rendering system.
- Build verification was not completed in this environment because npm dependency installation timed out. Run `npm install` and `npm run build` locally before deployment.
